# Quiz-App-FE

## Getting Started

This project is built with **React**, **TypeScript**, and **Material UI**, using **Vite** as the build tool.

### Installation

1. Clone the repository or download the project folder.
2. Open a terminal in the project root (`Quiz-App-FE`).
3. Install dependencies:

```bash
npm install
```

### Running the Application (Dev Mode)

Start the development server with:

```bash
npm run dev
```

Open your browser at `http://localhost:5173/` to view the app.
